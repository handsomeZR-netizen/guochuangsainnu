# 需求文档

## 简介

本项目旨在将现有的"墨韵智汇"平台重新聚焦于南通蓝印花布的全球活化与商业化，通过整合国产AI大模型（DeepSeek-V3用于文本逻辑，Doubao-Seedream用于视觉生成），打造一个集文化传承、产品定制、数据可视化于一体的沉浸式电商平台。核心场景包括"亲子手作"、"宴席定制"和"空间美学"三大方向。

## 术语表

- **系统 (System)**: 指南通蓝印花布全球活化平台的整体Web应用
- **蓝印花布 (Blue Calico)**: 南通传统手工印染工艺，使用天然靛蓝染料和刮浆防染技术
- **DeepSeek-V3**: 国产大语言模型，用于文化解读、文案生成和逻辑推理
- **Doubao-Seedream**: 豆包文生图模型，用于纹样生成和产品效果图预览
- **纹样 (Pattern)**: 蓝印花布上的传统吉祥图案，如"五福捧寿"、"松鹤长春"等
- **刮浆印染 (Scraping Paste Dyeing)**: 蓝印花布的核心工艺技术
- **3D地球组件 (Globe3D)**: 展示全球市场数据和贸易路线的Three.js可视化组件
- **靛蓝 (Indigo)**: 天然植物染料，蓝印花布的标志性颜色
- **亲子场景 (Parent-Child Scenario)**: 面向家庭教育的手作锦囊产品线
- **宴席场景 (Banquet Scenario)**: 面向婚宴、旅拍的定制画卷和桌旗产品线
- **空间场景 (Space Scenario)**: 面向家居软装和商业空间的诗布产品线

## 需求

### 需求 1: 品牌重塑与视觉升级

**用户故事:** 作为平台访问者，我希望看到明确聚焦于南通蓝印花布的品牌形象，以便快速理解平台的核心价值和文化定位。

#### 验收标准

1. WHEN 用户访问首页 THEN 系统应显示更新后的品牌名称"墨韵智汇：南通蓝印花布全球活化方案"
2. WHEN 用户浏览Hero区域 THEN 系统应展示包含"靛蓝"、"刮浆印染"等南通蓝印花布特色元素的视觉背景
3. WHEN 用户查看品牌标语 THEN 系统应显示"不止于布，是一场可生活的东方美学复兴"
4. WHEN 用户滚动页面 THEN 系统应保持蓝印花布的靛蓝色调（#1e3a8a, #3b82f6）作为主色调
5. WHEN 用户与页面交互 THEN 系统应展示靛蓝色的水墨拖尾效果

### 需求 2: 3D地球数据可视化恢复

**用户故事:** 作为平台运营者，我希望恢复3D地球组件来展示南通蓝印花布的全球市场分布和贸易路线，以便增强数据可信度和视觉冲击力。

#### 验收标准

1. WHEN 用户滚动到数据大屏区域 THEN 系统应渲染3D地球组件并显示全球热点城市
2. WHEN 3D地球加载完成 THEN 系统应显示从南通出发到全球主要城市的贸易路线动画
3. WHEN 用户鼠标移动 THEN 系统应响应鼠标位置并调整地球旋转角度
4. WHEN 地球组件不在视口内 THEN 系统应暂停渲染以节省性能
5. WHEN 窗口大小改变 THEN 系统应自动调整地球组件的尺寸和比例

### 需求 3: AI双模型架构集成

**用户故事:** 作为产品设计师，我希望使用DeepSeek-V3生成纹样的文化解读，并使用Doubao-Seedream生成产品效果图，以便为用户提供智能化的定制体验。

#### 验收标准

1. WHEN 用户输入纹样关键词（如"五福捧寿"）THEN 系统应调用DeepSeek-V3生成该纹样的文化含义和营销文案
2. WHEN DeepSeek-V3返回文化解读 THEN 系统应将解读内容展示在产品详情页面
3. WHEN 用户请求生成效果图 THEN 系统应调用Doubao-Seedream生成包含"南通蓝印花布"、"刮浆印染纹理"、"植物靛蓝"等特征的图像
4. WHEN Doubao-Seedream返回图像 THEN 系统应在预览区域显示高清效果图
5. WHEN API调用失败 THEN 系统应显示友好的错误提示并提供重试选项

### 需求 4: 三大场景产品展示

**用户故事:** 作为潜在客户，我希望清晰地看到"亲子手作"、"宴席定制"和"空间美学"三大产品场景，以便根据我的需求选择合适的产品。

#### 验收标准

1. WHEN 用户浏览产品展示区 THEN 系统应显示三个独立的场景分类卡片
2. WHEN 用户点击"亲子手作"场景 THEN 系统应展示手作锦囊、DIY染料包和儿童科普内容
3. WHEN 用户点击"宴席定制"场景 THEN 系统应展示靛蓝画卷、桌旗定制和3D宴席效果图
4. WHEN 用户点击"空间美学"场景 THEN 系统应展示软装诗布、屏风、挂画和透光灯罩产品
5. WHEN 用户查看任一场景 THEN 系统应提供AI辅助的产品推荐和搭配建议

### 需求 5: 文化溯源与教育内容

**用户故事:** 作为文化爱好者，我希望了解南通蓝印花布的历史、工艺和纹样寓意，以便更深入地理解产品的文化价值。

#### 验收标准

1. WHEN 用户选择一个纹样 THEN 系统应使用DeepSeek-V3生成该纹样在南通民俗中的详细寓意说明
2. WHEN 用户查看工艺介绍 THEN 系统应展示刮浆印染的完整流程和技术特点
3. WHEN 用户浏览亲子产品 THEN 系统应提供"儿童版"非遗科普故事
4. WHEN 用户扫描产品二维码 THEN 系统应跳转到对应的文化百科页面
5. WHEN 用户请求工艺视频 THEN 系统应播放南通老艺人的手工制作过程

### 需求 6: 智能定制与预览

**用户故事:** 作为定制客户，我希望上传我的设计草图或房间照片，并获得AI生成的效果预览，以便在下单前确认最终效果。

#### 验收标准

1. WHEN 用户上传设计草图 THEN 系统应使用Doubao-Seedream预模拟染色后的效果
2. WHEN 用户上传房间照片 THEN 系统应使用DeepSeek-V3分析色调并推荐适合的蓝印花布软装方案
3. WHEN AI生成推荐方案 THEN 系统应展示至少3种不同的纹样和布局选项
4. WHEN 用户选择一个方案 THEN 系统应生成该方案在用户空间中的3D预览效果
5. WHEN 用户确认定制 THEN 系统应将定制参数保存并生成订单

### 需求 7: 性能优化与用户体验

**用户故事:** 作为移动端用户，我希望页面加载快速且交互流畅，以便获得良好的浏览体验。

#### 验收标准

1. WHEN 页面首次加载 THEN 系统应在3秒内完成首屏渲染
2. WHEN 用户进行鼠标交互 THEN 系统应将INP（Interaction to Next Paint）控制在200ms以内
3. WHEN 3D组件不在视口内 THEN 系统应自动暂停渲染并释放70%的GPU占用
4. WHEN 用户快速滚动页面 THEN 系统应使用requestAnimationFrame节流处理事件
5. WHEN Canvas粒子数量超过30个 THEN 系统应停止生成新粒子以保持性能

### 需求 8: 多语言与海外市场支持

**用户故事:** 作为海外华人，我希望看到中英双语的产品介绍和情感化的营销文案，以便产生文化共鸣和购买意愿。

#### 验收标准

1. WHEN 海外用户访问平台 THEN 系统应根据IP地址自动识别并建议语言选项
2. WHEN 用户选择英文界面 THEN 系统应显示"跨越重洋的靛蓝，是写给时光的情书"等乡愁叙事文案
3. WHEN 用户选择中文界面 THEN 系统应显示"健康染于身，文化养于心"等中产家庭导向文案
4. WHEN 用户查看产品详情 THEN 系统应提供中英双语的纹样解读和工艺说明
5. WHEN 用户切换语言 THEN 系统应保持当前浏览状态和购物车内容

### 需求 9: 商业闭环与可持续发展

**用户故事:** 作为平台管理员，我希望建立"设计-订单-农户印染-质检-发货"的柔性供应链，以便实现规模化运营和文化传承。

#### 验收标准

1. WHEN 用户完成定制订单 THEN 系统应自动将订单分配给南通当地的合作艺人
2. WHEN 艺人完成制作 THEN 系统应触发质检流程并更新订单状态
3. WHEN 质检通过 THEN 系统应启动跨境物流并向用户发送追踪信息
4. WHEN 订单完成 THEN 系统应将销售利润的5%拨入"蓝印花布传承基金"
5. WHEN 基金达到阈值 THEN 系统应生成报告并通知管理员进行艺人补贴分配

### 需求 10: 数据大屏与市场分析

**用户故事:** 作为投资者，我希望看到南通蓝印花布的全球市场热度、价格趋势和竞品对比，以便评估产品的商业价值和投资潜力。

#### 验收标准

1. WHEN 用户查看数据大屏 THEN 系统应展示全球访问热力图，标注主要市场的访问量和订单量
2. WHEN 用户查看价格分析 THEN 系统应显示与Amazon、Etsy等平台同类产品的价格对比雷达图
3. WHEN 用户查看趋势曲线 THEN 系统应展示过去12个月的搜索热度和销售额变化
4. WHEN 用户点击某个数据点 THEN 系统应显示该时间点的详细数据和市场事件说明
5. WHEN 数据更新 THEN 系统应在页面上显示实时的交易流动画（"x秒前，来自y地的用户收藏/购买"）
